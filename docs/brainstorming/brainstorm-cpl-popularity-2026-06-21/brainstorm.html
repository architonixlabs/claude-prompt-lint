Why cpl isn't catching on —
and what it would take to go popular

A pre-mortem on a local-first prompt linter for Claude Code. The verdict isn't about the code. It's about where the tool decided to stand.

core diagnosis · 1 finding

The code is excellent; the product is mis-positioned. cpl leads with its weakest, most-annoying job (the quality gate) and buries its strongest felt jobs (secret-prevention, project-context). It also fights the platform trend instead of riding it.

Value prop targets a pain that's small and felt by a minority — "save clarification tokens" lands only for API-metered users; Max/Pro subscribers feel no per-token cost.

A clarification round-trip is cheap and fast — users don't experience it as painful enough to install a gate against it.

ux/success-is-invisible

📈 lens: Platform-Trend / existential check
error
The platform is the competitor. Claude Code increasingly plans and asks good clarifying questions; as models improve, the marginal value of pre-linting a human prompt shrinks. The tool fights the trend line.
strategy/against-the-trend

The hero feature (quality gate) is the weakest-value, most-annoying job. The strongest felt jobs are buried side features: mask (stop a secret leak) and init (keep repo context fresh for Claude).

The gate modality is the mistake — rewrite/expand are genuinely valuable, but as on-demand commands, not as a hot-path gate.

Quick Fixes

// generative ideas → suggested fixes

Each fix is an applicable move surfaced by First-Principles, Analogical, SCAMPER/Reverse, and Distribution lenses. Click fix it mentally — these compose.

fix it

Use the privileged interception point for what it's worth

lens · First Principles

The asset is the position: the last checkpoint before tokens are spent and before data leaves the machine, with full repo context, for free. Quality-linting is a low-value use of that seat. Data-loss prevention + context injection are the high-value uses.

fix it

Win like ESLint/Prettier/Grammarly did — fix or add, don't scold

lens · Analogical

ESLint/Prettier won via auto-FIX, not scolding. Grammarly won via constant visible, additive, accept-this suggestions. cpl's hero does neither — it warns and is ignorable. A hook can't silently rewrite the prompt in the hot path, so make /cpl rewrite the Grammarly-style hero — or coach Claude instead of the human.

fix it

Reverse the target — coach Claude, not the human

lens · SCAMPER / Reverse

Instead of judging the user, inject guidance for Claude: "user prompt lacks X, ask about it." This works with the platform trend, not against it.

cpl · interception behaviorreverse target
-warn the human: "your prompt is vague — add acceptance criteria"
+brief Claude: "prompt omits acceptance criteria — ask the user before acting"
fix it

Eliminate the warn-mode auto-gate default

lens · SCAMPER / Eliminate

Make the gate opt-in, and lead with the strong jobs — safety + context.

fix it

Combine init + mask as "the two things every CC repo needs day one"

lens · SCAMPER / Combine

Reposition cpl from nanny to day-one setup tool. mask = a real, scary, universal, felt pain (a leaked secret) — a far stronger install reason than "your prompt is vague." init (→ CLAUDE.md) is felt by everyone running Claude Code on a real repo, and grows more valuable as agents act autonomously.

fix it

Magnify stats into a shareable artifact

lens · SCAMPER / Magnify

"Caught N secrets / saved $X this month" — a social-proof loop, and the only shareable surface cpl has.

fix it

Put the eval engine to other use — grade prompt templates in CI

lens · SCAMPER / Put-to-other-use

The local prompt-eval engine could grade a team's prompt templates in CI — a B2B / team angle beyond the solo dev.

fix it

Ship a public artifact

lens · Distribution

A before/after rewrite gallery, a repo prompt-hygiene badge, a no-install web playground to try the rewriter — give the value somewhere to spread.

fix it

Frictionless try-before-install

lens · Distribution

A hosted playground or npx-style one-shot of the rewriter, so people experience value before the multi-step plugin install.

The code is excellent; the product is mis-positioned. cpl leads with its weakest, most-annoying job (the quality gate) and buries its strongest felt jobs (secret-prevention, project-context). It also fights the platform trend instead of riding it.

"Coach Claude, not the human." Inject guidance for the model to ask the right question. This converts the existential threat — Claude getting better at handling vague prompts — into a tailwind.

Reposition around secret-prevention + project-context as the install reason.
— demote the warn-mode auto-gate to opt-in.
